# 🤖 3x-UI Telegram Bot

Асинхронный Telegram-бот для управления пользователями и их профилями на **3x-ui** (панель управления XRay / VLESS).  
Бот создаёт и обновляет подключения, автоматически формирует **VLESS ссылки** и хранит данные пользователей в **PostgreSQL** и резервном `users.json`.

---

## 🚀 Основные функции

- 🔐 Авторизация на панели **3x-ui** через API  
- 🧾 Хранение данных пользователей в **PostgreSQL**  
- 💾 Резервное хранение данных в `users.json` при сбое БД  
- 🪄 Генерация `UUID` и автоматическое создание/обновление VLESS-ссылок  
- 🗑 Удаление старых профилей при создании нового  
- ⚙️ Полностью асинхронная архитектура (`asynio`,`aiogram`, `aiohttp`)  

---

## 🧠 Структура проекта
```
bot/
├── main.py # Точка входа, инициализация бота и запуск
├── handlers.py # Обработка сообщений и команд пользователей
├── work_with_3xui.py # Модуль для взаимодействия с API 3x-ui
├── work_with_bd.py # Работа с PostgreSQL (чтение, запись, обновление)
├── data.env # Хранение логинов, паролей, IP и портов для БД и панели
└── users.json # Резервное хранилище данных пользователей
```

## ⚙️ Установка

### 1️⃣ Клонирование репозитория
```bash
git clone https://github.com/sk-rrr/VinniePoohNetworks.git
cd VinniePoohNetworks
```
### 2️⃣ Установка зависимостей
```bash
pip install -r requirements.txt
```
### 🔐 Настройка окружения
Создай файл data.env (в корне проекта):

```env
# Telegram Bot
TOKEN=token_tg_bot

# PostgreSQL
DBNAME=name_your_db
USER=your_user
PASSWORD=your_password
HOST=your_host
PORT=your_port

# 3x-UI panel
IP3XUI=https://IP:HOST/randompath/panel
LOG3XUI=your_user
PASS3XUI=your_password
INBOUND=inbound_for_adding_users
VLESSPORT=port_for_vless
```

### ▶️ Запуск бота
```bash
python main.py
```
После запуска бот:
- подключится к PostgreSQL,
- начнёт обрабатывать команды Telegram,
- авторизуется в 3x-ui(при запросе),
- Сохранит данные в БД и создаст резервную копию данных в users.json при критической ошибке.

### 💬 Основные команды
|      Команда      | Описание                                       |
|:-----------------:|------------------------------------------------|
|      /start       | Приветствие и проверка регистрации             |
|  Получить ссылку  | Обновляет ссылку и отправляет пользователю     |
|    Инструкция     | Возвращает инструкцию для использования ссылки |
|        /v         | Верификация пользователя админом               |
|        /dv        | Удаления пользователя админом                  |

### 🗄 Структура базы данных PostgreSQL
|  Поле    | Тип данных  | Описание                                 |
|:--------:|:-----------:|------------------------------------------|
|  tg_id   |   BIGINT    | Telegram ID пользователя                 |
|   name   | VARCHAR(20) | Имя пользователя                         |
| lastname | VARCHAR(20) | Фамилия пользователя                     |
|   uuid   | VARCHAR(36) | Уникальный идентификатор профиля в 3x-ui |
|  admin   |   BOOLEAN   | Флаг администратора                      |

💡 При сбое соединения с БД данные автоматически сохраняются в users.json.
